# Controle de Projetos

## 📋 Sobre o Projeto

Sistema de gerenciamento que estabelece a relação entre funcionários e projetos através de uma API REST. A aplicação permite visualizar quais funcionários estão alocados em determinado projeto, bem como identificar todos os projetos nos quais um funcionário específico está envolvido.

## 🚀 Funcionalidades Principais

O sistema oferece as seguintes capacidades:

- Cadastro e gerenciamento de funcionários
- Cadastro e gerenciamento de projetos
- Associação de funcionários a projetos
- Consulta de funcionários por projeto
- Consulta de projetos por funcionário
- Visualização completa dos dados de funcionários e projetos
